# بوت تليجرام — المساعد الذكي بتاع علي 🤖

بوت تليجرام بيرد عليك بذكاء اصطناعي، شغال مجاناً بالكامل:
المخ الأساسي **Groq** (سريع ومجاني)، ولو وقع بيحوّل تلقائياً على **Gemini** (جوجل، مجاني برضه). الاستضافة على **Render** المجاني.

مفيش أي مفتاح أو توكن مكتوب في الكود، كله بيتظبط من متغيرات البيئة (Environment Variables).

## اللي محتاجه قبل ما تبدأ

1. حساب تليجرام
2. حساب جوجل (عشان مفتاح Groq، وعشان Gemini لو حبيت)
3. حساب GitHub + حساب Render (مجانيين)

## الخطوة 1: اعمل البوت في تليجرام

1. افتح تليجرام ودور على **@BotFather**
2. ابعت `/newbot`
3. اختار اسم للبوت (مثال: مساعد علي الذكي)
4. اختار يوزرنيم لازم ينتهي بـ `bot` (مثال: `ali_smart_assistant_bot`)
5. هيبعتلك **توكن** طويل شكله زي `123456:ABC-DEF...` — انسخه واحتفظ بيه، ده مفتاح البوت، متبعتوش لحد.

## الخطوة 2: اعمل مفتاح Groq المجاني

1. ادخل على https://console.groq.com وسجّل دخول بحساب جوجل
2. من القايمة اختار **API Keys** ثم **Create API Key**
3. انسخ المفتاح (بيبدأ بـ `gsk_...`) واحتفظ بيه، مش هيظهر تاني.

الحد المجاني بتاع Groq: حوالي **1000 طلب في اليوم** و30 طلب في الدقيقة على الموديل المستخدم هنا. لو خلّص الحد، البوت هيحوّل على Gemini لو مظبطه، أو هيرد برسالة اعتذار.

لو عايز Gemini احتياطي (اختياري): ادخل على https://aistudio.google.com وسجّل دخول بجوجل، واضغط **Create API Key** وانسخ المفتاح.

## الخطوة 3: ارفع الكود على GitHub

1. اعمل حساب على https://github.com لو معندكش
2. اعمل Repository جديد (مثال: `telegram-assistant-bot`)
3. ارفع الملفات دي كلها: `bot.py` و`requirements.txt` و`render.yaml` و`.env.example`
4. **مهم:** متحطش أي ملف `.env` فيه مفاتيح حقيقية على GitHub أبداً.

## الخطوة 4: شغّله على Render المجاني

1. ادخل على https://render.com وسجّل دخول بحساب GitHub
2. دوس **New +** ثم **Web Service** واختار الريبو بتاعك
3. اختار الخطة **Free**
4. اتأكد إن أوامر التشغيل كده:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python bot.py`
5. في قسم **Environment Variables** ضيف:
   - `TELEGRAM_BOT_TOKEN` = التوكن بتاع @BotFather
   - `GROQ_API_KEY` = مفتاح Groq
   - `GEMINI_API_KEY` = مفتاح Gemini (اختياري)
   - `RUN_MODE` = `webhook`
   - `ALLOWED_USER_IDS` = رقم الـ ID بتاعك على تليجرام (عشان محدش غيرك يستخدم البوت — اعرف رقمك من بوت @userinfobot)
6. دوس **Deploy** واستنى لحد ما يكتب **Live** واللوج يبقى من غير أخطاء.

## قفل البوت عليك بس (مهم للأمان)

**مقفول افتراضياً:** لو `ALLOWED_USER_IDS` فاضي أو مش متظبط،
البوت **مش هيرد على حد خالص** — حتى انت. لازم تحط رقمك.
والغريب اللي يبعت للبوت مش بياخد أي رد أصلاً، عشان البوت
ميأكدش وجوده. من غير القفل ده، أي حد يلاقي البوت يقدر يكلمه
ويستهلك حد Groq المجاني بتاعك. عشان البوت يرد عليك انت بس:

1. افتح تليجرام، ودور على بوت **@userinfobot**، وابعتله أي رسالة
2. هيرد عليك برقم الـ ID بتاعك (رقم طويل، مثال: `123456789`)
3. حط الرقم ده في `ALLOWED_USER_IDS` في ملف WSGI على
   PythonAnywhere (أو في متغيرات البيئة على Render)، بالشكل ده:
   `ALLOWED_USER_IDS = "123456789"`
4. اعمل **Reload** (أو إعادة تشغيل) بعد ما تحفظ

بعدها البوت مش هيرد على أي حد غيرك أصلاً (ولا حتى برسالة رفض).
ومتحطش رقم الـ ID بتاعك في أي ملف على GitHub أبداً.

ملحوظة أمان: رابط الـ Webhook هو `/webhook` عادي من غير أي سر،
والسر (`WEBHOOK_SECRET`) تليجرام بيبعته في هيدر
`X-Telegram-Bot-Api-Secret-Token` مع كل رسالة — السر ده قيمة
عشوائية انت بتختارها، والتوكن مبيظهرش في أي رابط، لأن لوجات
السيرفر بتسجّل الروابط كاملة. ولوج httpx متظبط على
WARNING عشان ميسجّلش طلبات فيها التوكن.

الحماية ضد حقن الأوامر: البوت بيشيل سطور الأوامر اللي بتحاول
تغيّر تعليماته قبل ما تبعت للذكاء الاصطناعي. دي حماية إضافية
على قدّها — والمهم إن مفيش أي مفتاح أو توكن في سياق المحادثة
أصلاً، فالخطر العملي قليل.

ملحوظة: Render بيظبط لوحده متغيرين، `PORT` و`RENDER_EXTERNAL_URL`، فمش محتاج تضيفهم.

## الخطوة 5: جرّب البوت

1. افتح البوت بتاعك على تليجرام ودوس **Start** أو ابعت `/start`
2. المفروض يرد عليك برسالة ترحيب بالعربي
3. ابعت أي سؤال، وهيرد عليك
4. جرّب `/new` عشان تبدأ محادثة جديدة، و`/help` عشان تشوف الأوامر

## حدود الخطة المجانية (اعرفها عشان متتفاجئش)

- **Render المجاني بينام:** لو محدش كلّم البوت 15 دقيقة، الخدمة بتقف، وأول رسالة بعد كده بتاخد حوالي دقيقة لحد ما تصحى. ده طبيعي في المجاني. لو عايزه يصحى أسرع، ممكن خدمة زي UptimeRobot تضرب رابط التطبيق كل 10 دقايق، بس ده بيستهلك من ساعات Render المجانية (750 ساعة في الشهر، يعني حوالي شهر كامل لو شغال على طول).
- **Groq المجاني:** 1000 طلب في اليوم. للاستخدام الشخصي كفاية جداً. لو خلّص، البوت هيحوّل على Gemini أو هيعتذر لحد تاني يوم.
- **الذاكرة:** البوت بيفتكر آخر 10 رسايل بس في المحادثة، ولو اتقفل واتفتح تاني بينسى اللي فات. ده مقصود عشان ميتخطاش حدود التوكنات.

## تشغيله على جهازك للتجربة (اختياري)

```bash
cp .env.example .env
# حط التوكن والمفاتيح الحقيقية في ملف .env
pip install -r requirements.txt
RUN_MODE=polling python bot.py
```

وبعدين جرّب البوت على تليجرام. وضع الـ polling للتجربة بس، الإنتاج لازم يبقى webhook على Render.

## حل المشاكل

| المشكلة | الحل |
|---|---|
| البوت مش بيرد خالص | اتأكد إن حالة الخدمة على Render **Live**، وإن `TELEGRAM_BOT_TOKEN` صح ومفيش مسافة زيادة. جرّب تعمل **Manual Deploy** تاني. |
| بيرد "حصلت مشكلة ومقدرتش أرد" | دي رسالة فشل الذكاء الاصطناعي. اتأكد إن `GROQ_API_KEY` صح، أو إنك مخلصتش حد الـ 1000 طلب اليومي. بص على لوج Render هيقولك السبب. |
| بيرد ببطء أول رسالة بعد فترة | ده نوم Render المجاني، استنى دقيقة وهيرد. |
| حد غيرك بيستخدم البوت | ضيف رقم الـ ID بتاعك في `ALLOWED_USER_IDS` على Render، واعمل إعادة تشغيل للخدمة. |
| خطأ عن الـ webhook | اتأكد إن `RUN_MODE=webhook` وإن رابط التطبيق العام صح. Render بيظبط `RENDER_EXTERNAL_URL` لوحده. |
| `TELEGRAM_BOT_TOKEN is not set` | التوكن مش متظبط في متغيرات البيئة على Render أو في ملف `.env` محلياً. |
